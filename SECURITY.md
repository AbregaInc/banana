# Reporting a security issue

Please send suspected vulnerabilities privately to **support@abrega.com** with
the subject **Banana security report**. This is the existing project support
address. Do not open a public issue containing an exploit, a token, personal
information or another user's data.

Include the affected client/service version or commit, expected and observed
behaviour, and a minimal reproduction using your own test account or synthetic
data. Redact passwords, OAuth credentials, session/share links, health data and
calendar contents. We do not publish an acknowledgement or resolution SLA.

Do not test against other users' accounts, run availability tests, or access data
you do not own. This policy is a reporting channel, not authorization for testing
production systems or a bug-bounty offer.

## Supported versions

The current official client release and current deployed service are the primary
maintenance targets. Historical benchmark revisions and experimental prototypes
are retained for research; they are not supported production releases. Reports
about older revisions are still useful when the issue may affect current code.
