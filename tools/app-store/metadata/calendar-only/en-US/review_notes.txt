Banana 1.0.1 adds Assistant to its calendar, reminders, routines, alarms, booking and travel time. Workouts, Food, Notes, Podcasts, Email and the Watch app are compiled out. There are no purchases.

DESKTOP LINK AND INCOMING CONNECTIONS (MAC)
The com.apple.security.network.server entitlement lets Desktop Link accept a direct connection from a paired iPhone or iPad. The listener starts when the user enables Desktop Link and resumes on launch while paired. The bundled Mac inference worker also listens on loopback for requests from Banana itself.

1. Put both devices on the same Wi-Fi network. On Mac, open Settings > Desktop Link > Enable desktop link. Allow Local Network access if prompted.
2. When the Mac model is ready, open Settings > Desktop Link on iPhone or iPad and tap Scan Mac QR code. You can also copy the code from the Mac and enter it manually.
3. Tap Check connection to verify the local network route. Ask Assistant “What’s on my calendar today?” Its model status shows the paired Mac. Turn off and revoke pairing on the Mac closes the listener and revokes access.

The Mac advertises _banana-link._tcp over Bonjour. The pairing secret authenticates and encrypts the direct connection. When the Mac is discovered locally, inference requests stay on the local network. Tailscale and the optional encrypted Banana Cloud relay support connections away from home. The camera is used when the user scans the pairing code.

MODEL DOWNLOADS (MAC)
Banana downloads model weights, tokenizer and configuration data to its data folder. The inference runtime ships in the signed app. Banana verifies the catalog signature and the size and SHA-256 hash of each downloaded file. The catalog can change which compatible model powers the existing Assistant feature. The catalog request carries no prompts, calendar data or account credentials. Apple’s on-device model can answer on supported devices while the Mac model downloads.

CALENDAR REVIEW
Choose Explore an example on the welcome screen for a fictional local workspace. Switch Day and Week, change calendar visibility, create, edit or delete sample events, and complete a reminder or routine. With the Google account in App Review Sign-In Information, use Continue with Google on the calendar step or Settings > Accounts & calendars > Connect Google Calendar to test live calendar access. The Not now option skips Google.
