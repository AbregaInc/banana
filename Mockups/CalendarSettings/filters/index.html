All events

One interaction, wherever you’re filtering.

Type a sentence to see filters appear automatically. Edit a filter or remove one. Results update automatically as you type or edit a chip. “With Alex” asks which person you mean. Any remaining words become a visible text filter.

This is a browser prototype with a deliberately small vocabulary and sample records. It does not connect to your accounts or modify the app. Dates use a fixed example week; production would resolve them using your calendar and timezone.

The intended native implementation uses standard search tokens and filter controls. The shared filter definition would sync across surfaces; a module only offers fields that its data source can actually filter.
