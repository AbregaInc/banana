# Frame instrumentation probes

The full Animation Hitches template exhausted free disk space and blocked UI capture. It was
stopped; raw kernel bytes were losslessly archived and hash-verified before reclaiming their
duplicate. The incomplete trace and archive remain local. Seven completed synthetic podcast
fixture databases were similarly archived and verified; no workspace or user backup was removed.
Inactive compiler/index caches were reclaimed while retaining sources, built products and results.

Logging plus Frame Lifetimes completed a 5-second schema probe. Logging plus Hitches, Frame
Lifetimes, Commits and Run Loops completed an 8-second schema probe. Their data includes
system presentation as well as app-attributed intervals. Unknown display identifiers and missing
event-latency values must not become invented input/display acceptance. Raw trace tables can
include process environment metadata and remain local.

The subsequent 45-second minimal-hitch recording completed the unchanged input recipe, but
Instruments spent the remainder of the 225-second recorder deadline in its frame-activity analysis.
The bounded wrapper interrupted processing; its result failed to export with Document Missing
Template Error. The failed recording is retained, not substituted with the shorter probes.
The normal commit/run-loop collector remains the established comparison path.

Apple describes [frame lifetime](https://developer.apple.com/documentation/xcode/understanding-hitches-in-your-app)
as a multi-stage pipeline interval: it is not a per-frame CPU-work duration and must not be
compared directly with the 8.3 ms CPU/render budget.
