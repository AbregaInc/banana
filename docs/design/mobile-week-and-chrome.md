# Week edges, floating controls and the app badge

On iPhone and iPad, the native week scroller rubber-bands beyond either week edge. A small pull returns to the current week; a deliberate horizontal pull starting at the boundary commits one adjacent week on release. Fling prediction alone cannot turn a week. Interior column scrolling, vertical gestures, pinching and event dragging retain their existing roles. A full-width iPad week can pull in either direction. Forward paging lands at the first column; backward paging shows the last days, preserving the live vertical time position. Reduced Motion suppresses the page transition.

UIKit supplies the elastic interaction. The release decision uses constant-size geometry without rebuilding the grid during finger movement. Only the small date/all-day strips observe the paired content/stretch offset. These choices preserve direct manipulation and familiar scrolling behavior; they are not a claim of measured frame or input latency.

The bottom shell has no opaque rectangular background or bottom scroll-edge mask. Content extends beneath the independently glass-backed buttons and search field. Safe-area and scroll-content insets still let the final item clear the controls; keyboards and expanded composers retain their existing placement and their own readable surfaces. Wide rail layouts retain their normal edge treatment.

The system app badge adds Plan, Food, Taken and enabled Mail's unified Inbox unread conversations. Mail-only changes update the total; disabled Mail is excluded. The initial zero clears an old badge, and equal totals are not rewritten. Cold/background startup uses the cached Mail count, followed by a read-only index count after account hydration; a newer live publication wins over an older read. Notification-daemon calls remain serialized off the main thread.

Tests cover boundary versus interior pulls, short/vertical/invalid pulls, full-width iPad paging, round trips and preserved time position; native rotation and creation journeys remain separate. Rotation uses a populated fixture week and a fixed opening hour rather than assuming every column around today's date contains events. Badge tests cover changes, disabling, duplicate suppression and zero. Calendar/Mail underlap journeys check viewport geometry and reachable controls, with screenshots for visual review. Component results do not establish physical 120 Hz or input-to-visible acceptance.
