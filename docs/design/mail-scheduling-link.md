# Scheduling links in a draft

The calendar-and-clock button beside the existing attachment and formatting tools inserts the account's confirmed Booking link. It is available in replies and new messages on iPhone, iPad and Mac. A caret inserts a clickable address and a non-linked separating space; selected words retain their text and formatting and receive the link. The clipboard and recipients are unchanged, and the existing draft model saves the edit.

A missing link or a handle awaiting confirmation opens the existing Booking settings. An unclaimed suggested address is never inserted. Opening this sheet hides the keyboard without folding away its presenting composer; closing settings preserves the draft. Read-only foreign drafts cannot be changed through this action. When the writing controls and Send cannot fit on one line, the footer uses two rows, preserving full touch targets on smaller phones and with larger text.

This applies proximity and familiar editor behavior: one direct action lives with the other writing tools, retains the selection, and uses the native attributed-text replacement API. Native formatting tests check Unicode, selection, safe schemes, link boundaries and repeated requests; composer tests check durable draft/recipient retention. Phone and iPad checks exercise keyboard-up insertion, Send reachability, draft reopening and setup recovery. Functional and compile checks do not establish physical input-to-visible latency or 120 Hz rendering performance.
