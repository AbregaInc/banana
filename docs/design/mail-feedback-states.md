# Mail feedback and nutrient reads

Mail actions report the state the provider has actually confirmed. Sending remains cancellable during the existing hold. Delivery acknowledgement changes the toast to **Sent**; **Send and Done** becomes **Sent and Done**, with **Undo Done** restoring the conversation without promising to retract the email. A definitive failure retains the draft and offers Retry through the existing durable send path. Message cards distinguish queued, sending, waiting for a connection, unconfirmed and failed delivery. Only an active send shows a spinner.

An invitation lookup keeps a visible loading, missing or failure state, with Retry for the latter two. Yes, No and Maybe appear only for a matching calendar event on the connected account's owned calendars. Account and invitation identity scope the lookup; late results cannot replace another card. Original invitation links remain available. This applies visibility of system status and recoverability without adding navigation or another permission flow.

Small graphics inside semantic data tables can carry status. Preserve their text alternative and use the existing formatted renderer when text-only native cells cannot represent the graphic. Tracking pixels remain excluded and the existing remote-image permission policy still applies. Prepared-body version 7 schedules existing cached messages for the normal preparation worker.

The read-only `read_nutrients` capability estimates supported nutrients from USDA food references and logged portion weights. It leaves the active chart unchanged, reports unknown measurements separately from measured zero, and continues to a written answer. Relative periods use the native clock; explicit dates must come from the request. It cannot establish complete dietary intake, supplements, deficiency or a personal target. Sample records are labelled as samples.

The catalog adds 208,825 measurements for 17 nutrients from the same USDA releases as the existing food database. Food IDs, macro values, portions and search ranking data remain unchanged. The bundled database grows by about 6 MB. Rebuild with `tools/build_food_database.py`, or augment the matching catalog with `tools/build_food_nutrients.py`; `tools/test_build_food_nutrients.py` covers zero/missing values, duplicate measurements, unit validation and transactional failure. Sources are [USDA FoodData Central](https://fdc.nal.usda.gov/download-datasets/) and the contextual [NIH choline reference](https://ods.od.nih.gov/factsheets/Choline-HealthProfessional/).

Native correctness tests, phone and iPad UI journeys, JavaScriptCore conformance and a real on-device-model proof cover these states. Component timing evidence is separate from physical frame and input latency acceptance; adding a nutrient capability is not a measured performance improvement.
