# Node.js October 21, 2026 security release

Reviewed https://nodejs.org/en/blog/vulnerability/october-2026-security-releases and
https://nodejs.org/en/blog/release/v24.22.1/. Fixed release for our supported LTS line:
**24.22.1**. Previous local build runtime: 24.18.0.

## Deployment scope

- Stable/Beta API, booking and cloud app: managed Cloudflare Workers (`Service/src/worker.js`),
  D1, Durable Objects and R2. No Node host/container is configured in this checkout.
- Website: static Cloudflare Workers assets (`LandingPage/wrangler.toml`).
- Optional Node service: `Service/src/node.js`, using Node SQLite, HTTP/2, filesystem and fetch.
- Node tooling: Wrangler, tests and local preview tools.

Cloudflare uses its own V8-isolate runtime, not a deployable Node binary:
https://developers.cloudflare.com/workers/reference/how-workers-works/.
The live production version metadata confirms compatibility date 2025-10-01 and no Node
compatibility flags. The Worker bundle excludes the Node entry, runtime check, SQLite and
HTTP/2 adapters. The advisory's Node implementations therefore do not directly describe our
Worker runtime. Shared native library/trust-store remediation remains Cloudflare's responsibility;
this review does not certify the absence of corresponding vulnerabilities inside their fleet.
Changing compatibility_date or redeploying identical application code is not a runtime patch.

## Changes

Pinned Node 24.22.1 in the repository version file and the Service/LandingPage Volta settings.
Service supports patched 24.x LTS releases, with strict npm engine enforcement and an executable
startup check, including direct `node src/node.js` invocation. npm test/start perform the same
preflight. Added a service CI workflow using the version file, npm ci and both timezone suites.
Other Node major lines require explicit validation before support is added.

## Validation

- Installed/fetched 24.22.1 through Volta; both cloud tooling folders resolve to that version.
- npm ci succeeded; production dependency audit reported zero known vulnerabilities. This audit
  does not assess Node native runtime CVEs.
- 256 tests passed in UTC and 256 in America/New_York on 24.22.1. Boundary tests reject 24.22.0,
  older releases, unsupported majors and prereleases. Actual local Node 24.18.0 was rejected.
- Real Node entry started against disposable storage and returned 200 `ok` from /v1/health.
- Service and website Wrangler 4.151.2 dry-run builds succeeded under patched Node.
- Stable/Beta health endpoints, both cloud app roots and website root all returned 200.
- Current production Worker: ea4e210f-2843-4872-be03-ba505cc7109f; Beta: 624f4415-de53-4bec-bedb-b001e76b69bd.
  No Worker code/runtime configuration changed and no production redeployment was necessary.

Raw logs, deployment metadata, audit and live checks are retained locally at
`~/Library/Logs/Banana/NodeSecurity-20261021`. CI workflow validation was local;
there is no Git remote configured in this checkout, so no hosted CI run or push is claimed.
